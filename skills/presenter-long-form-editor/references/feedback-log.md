# Presenter long-form editor feedback log

Record the creator's feedback on edits made with this skill, newest last. Each entry is a lesson the
skill should keep, not a transcript.

Promote a lesson into `brand-system.md` when the creator states it as a standing preference or when it
recurs. Do not turn a one-off correction into a universal rule. Preserve earlier entries instead of
rewriting them.

## Entry format

```markdown
## YYYY-MM-DD: <short title>

Artifact: <project and version, for example my-intro-v2>
Observed issue: <what was wrong, in the creator's words where possible>
Correction: <what changed>
Reusable lesson: <the rule to follow next time>
```
